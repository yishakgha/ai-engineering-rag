# AI Engineering RAG Project

## Overview

This project implements a Retrieval-Augmented Generation (RAG) chatbot that answers employee questions using company policy documents.


## Technologies

- Python 3.12
- LangChain
- ChromaDB
- Sentence Transformers
- Streamlit
- Groq API

## Project Structure

- `data/policies/` - Company policy documents
- `src/` - RAG implementation
- `vector_db/` - Chroma vector database
- `tests/` - Unit and integration tests
- `evaluation/` - Evaluation results
